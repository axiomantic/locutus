Axiomantic Locutus APT Repository

Official Debian/Ubuntu package repository for Locutus (amd64 & arm64).

Installation via APT

# 1. Add repository to sources
echo "deb [trusted=yes] https://axiomantic.github.io/locutus/apt/ ./" | sudo tee /etc/apt/sources.list.d/locutus.list

# 2. Update and install
sudo apt-get update
sudo apt-get install -y locutus

Homebrew Installation (macOS & Linux)

brew install axiomantic/tap/locutus

Universal One-Line Installer

curl -fsSL https://raw.githubusercontent.com/axiomantic/locutus/main/scripts/install.sh | bash

For documentation, source code, and release downloads, visit the Locutus GitHub Repository.
